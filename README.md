# userScript_para_tamperMonkey

# Atendente WhatsApp

Script para Tampermonkey que adiciona automaticamente o nome do atendente antes das mensagens enviadas no WhatsApp Web.

---

# Sobre o Projeto

Este projeto foi desenvolvido para facilitar atendimentos realizados por múltiplos operadores dentro do WhatsApp Web.

O script intercepta o envio da mensagem e adiciona automaticamente um prefixo contendo o nome do atendente.

Exemplo:

```txt
[Atendente] Olá cliente, tudo bem?
